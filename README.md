# Check-In-Bot
Finds a check-in message for the current hour and posts it to a Discord channel.

## Project Goal
Automate the process of sending check-in messages to notify people of their upcoming shifts and eliminate the possibility of someone forgetting to send it.

## MVP
The bot will be able to connect to a spreadsheet, read the data from the cells of it, and send it to a specified Discord channel.

## Future Plans
Keep track of who has/hasn't checked in, send a message when everyone has checked in, only run when there is a swap.

## Tech Stack
NodeJS, Google API, Discord Interactions, cron, Google Sheets (as a source), Discord (for output)
